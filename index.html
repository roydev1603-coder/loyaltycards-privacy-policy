Politique de confidentialité – Loyalty Cards

Dernière mise à jour : 29 mai 2026

Bienvenue sur Loyalty Cards.
La protection de vos données personnelles est importante pour nous. Cette politique de confidentialité explique quelles informations sont collectées, comment elles sont utilisées et protégées lorsque vous utilisez notre application mobile.

1. Informations collectées

L’application peut collecter les informations suivantes :

a) Informations de connexion

Lorsque vous vous connectez avec Google, nous pouvons collecter :

  • Votre nom
  • Votre adresse e-mail
  • Votre photo de profil Google (si disponible)

Ces informations sont fournies par Google via Firebase Authentication.

b) Données des cartes de fidélité

Lorsque vous utilisez l’application, les informations suivantes peuvent être enregistrées :

  • Nom du magasin
  • Numéro de carte
  • Nom du titulaire
  • Catégorie
  • Logo ou image de la carte

Ces données sont enregistrées :

  • localement sur votre appareil (Hive)
  • et/ou dans le cloud via Firebase Firestore lorsque la sauvegarde cloud est activée.

2. Utilisation des données

Les données collectées servent uniquement à :

  • sauvegarder vos cartes de fidélité
  • synchroniser vos données entre plusieurs appareils
  • restaurer vos cartes après réinstallation
  • améliorer l’expérience utilisateur

Nous ne vendons ni ne partageons vos données personnelles à des tiers.

3. Stockage et sécurité

Les données sont stockées de manière sécurisée grâce aux services Firebase de Google.

Nous mettons en œuvre des mesures raisonnables pour protéger vos informations contre :

  • l’accès non autorisé
  • la modification
  • la perte
  • la divulgation

4. Connexion Google

L’application utilise Google Sign-In pour permettre :

  • l’authentification sécurisée
  • la sauvegarde cloud des cartes

Google peut collecter certaines informations conformément à sa propre politique de confidentialité :

Politique de confidentialité Google

5. Partage des données

Nous ne partageons aucune donnée personnelle avec des sociétés tierces, sauf :

  • lorsque cela est requis par la loi
  • pour fournir les services Firebase nécessaires au fonctionnement de l’application

6. Vos droits

Vous pouvez à tout moment :

  • supprimer vos cartes
  • désactiver la sauvegarde cloud
  • vous déconnecter de votre compte Google

Pour demander la suppression complète de vos données cloud, contactez-nous à l’adresse ci-dessous.

7. Conservation des données

Les données sont conservées :

  • tant que votre compte reste actif
  • ou jusqu’à leur suppression manuelle par l’utilisateur

8. Enfants

L’application n’est pas destinée aux enfants de moins de 13 ans.

Nous ne collectons pas sciemment des données personnelles concernant des enfants.

9. Modifications

Cette politique peut être mise à jour à tout moment.

Les modifications importantes seront indiquées dans l’application ou via la fiche Play Store.
